# Передача задач
База контрактов для S01–S08: тег contracts-v1 (git rev-parse contracts-v1). Для следующей волны использовать также перечисленные зависимости. Работать в отдельной ветке codex/sNN от переданного коммита и отдельном worktree. Один исполнитель на строку. Не менять общий каталог, правила, зависимости, интерфейсы или чужие модули. Интегратор принимает по одному коммиту с проверками. Если контракт неоднозначен, сообщить интегратору с примером.

К каждой строке приложить этот файл, docs/SPEC.md, docs/CONTRACTS.md, src/robotization_bench/contracts.py, data/world_spec.json, data/plans/, pyproject.toml, uv.lock (или передать коммит целиком). Строка вместе с этими файлами — самостоятельное задание; отдельных исходных S01–S08 в загрузках нет.

|ID|Когда начинать|Владение (пути .py внутри src/robotization_bench, тесты внутри tests)|Результат и проверка|
|---|---|---|---|
|S01|готово к выдаче|scenarios.py, data/development/*.json, test_scenarios.py|Стабильный генератор; проверить известную волну, сортировку и идентичность сохранённых дней|
|S02|готово к выдаче|validation.py, test_validation.py|Строгий глубокий разбор, одинаковая спецификация dict/текста, атаки типами и лишними полями|
|S03|готово к выдаче|economics.py, test_economics.py|Чистая экономика; независимо просчитать пример с покупкой, простоем, браком и сверхурочными|
|S04|после ядра, сервиса и scripts/run_bench.py|cli.py, test_cli.py|Рабочие команды, понятные ошибки, корректный код выхода|
|S05|после Episode|mcp_server.py, test_mcp.py|MCP SDK из lock; отдельное состояние процесса; пройти настоящий stdio observe/pilot/submit|
|S06|после движка|test_invariants.py|Независимая проверка по событиям: интервалы, резервы, сохранность, H, переделка и клин|
|S07|после первых трасс и Evaluation|reporting.py, test_reporting.py|Сравнение без ложных выводов, поток событий JSONL для 3D|
|S08|после сквозного запуска|README.md, AGENT.md|Одна команда, краткий бриф, чистый запуск, ограничения, реальные статусы|

Интегратор: все прочие файлы, проверка пакета, стратегий, слияния, фиксация результатов и статусов. Handoff: сообщить hash, список файлов, команду теста и замеченные ограничения.
