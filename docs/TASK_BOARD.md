# Передача задач
База контрактов для S01–S08: тег contracts-v1 (git rev-parse contracts-v1). Для следующей волны использовать также перечисленные зависимости. Работать в отдельной ветке codex/sNN от переданного коммита и отдельном worktree. Один исполнитель на строку. Не менять общий каталог, правила, зависимости, интерфейсы или чужие модули. Интегратор принимает по одному коммиту с проверками. Если контракт неоднозначен, сообщить интегратору с примером.

К каждой строке приложить этот файл, docs/SPEC.md, docs/CONTRACTS.md, src/robotization_bench/contracts.py, data/world_spec.json, data/plans/, pyproject.toml, uv.lock (или передать коммит целиком). Строка вместе с этими файлами — самостоятельное задание; отдельных исходных S01–S08 в загрузках нет.

|---|---|---|---|
|S01|готово к выдаче|scenarios.py, data/development/*.json, test_scenarios.py|Стабильный генератор; проверить известную волну, сортировку и идентичность сохранённых дней|

Интегратор: все прочие файлы, проверка пакета, стратегий, слияния, фиксация результатов и статусов. Handoff: сообщить hash, список файлов, команду теста и замеченные ограничения.

## Контрольные точки интегратора
- A: пустое дерево main без remote и предыдущих коммитов; AGENTS и стартовой сборки не обнаружено. Контракты — тег contracts-v1. Первые черновые расстановки не выдержали всплески заказов. На публичных днях заменили только состав/порядок зон в примерах; числа мира и контракты не менялись.
- B: вручную сверены один и два заказа. Один работник и regular: интервалы [0,3), [3,10), [10,23), [23,28), включая три перехода. При H=28 заказ годен; при H=27 числится в работе. Для двух regular с поступлением на тике 0 выходы — 28 и 58. Затем проверены волны и целые смены.
- C: ручной baseline допустим; контрольный поиск проверен на всех трёх публичных днях. Ядро и политика заморожены тегом local-policy-v1 до открытия восьми новых дней. Файлы протокола повтора — evidence/.
- D: SDK и клиент MCP проверены локально. Подтверждён разбор адаптера Harbor; реальный запуск остановился до контейнера (нет Docker). Нет пакета мероприятия или результатов сильного агента. Следующие действия — docs/HARBOR.md.
- E: локальный оценщик, попытки подмены, неполные сдачи, разделение сборочных контекстов и чистый повтор проверяются отдельно. Конкурсный эксперимент и анализ трёх попыток модели остаются открыты.
