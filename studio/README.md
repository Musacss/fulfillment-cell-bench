# 4 Horses Replay Studio

Локальный Three.js-плеер рассчитанных смен. Из корня репозитория в двух терминалах:

```bash
bash scripts/start_3d_bridge.sh
```

```bash
bash studio/start.sh
```

Открыть [http://127.0.0.1:5173](http://127.0.0.1:5173). Первый процесс экспортирует `manual/candidate/reference` для сидов `11/29/47` и отдаёт данные на `8765`. Второй проверяет 15 исходных GLB, готовит веб-ассеты и запускает Vite. Node.js ищется в системе или runtime Codex; зависимости устанавливаются при необходимости.

Можно выбрать одиночный прогон, сравнить два плана на одном seed или открыть локальные `manifest.json` + `events.jsonl` кнопкой «Открыть файлы». Кнопка «Папка» загружает полный пакет, включая каталог или квартальные недели. Для квартала используется тот же код сменного реплея; реальный квартальный Python-модуль в текущей ветке отсутствует, формат проверен на 12 тестовых неделях.

Play/Pause, перемотка, скорости 1×–100×, переход к важному событию, камеры и шесть слоёв управляют только просмотром. OpEx смены, отдельный CapEx и Evaluation по явно указанным сидам берутся из пакета. Существующие GLB и Python-ядро не изменены.

Проверка из корня: `node scripts/check_replay_player.mjs`. Отчёт: `artifacts/player-check/report.json`. Сборка: `npm --prefix studio run build` или `pnpm --dir studio run build`.

Подробности запуска, пространственной стыковки, проверок и полный список файлов: [3D_PLAYER_STUDIO.md](../docs/ru/3D_PLAYER_STUDIO.md).
